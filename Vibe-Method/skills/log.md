## Rôle
**`/log`** — Met à jour `[projet].log.md` (journal de bord de session). **T1 — Haiku (optionnel).**

## Output
Nouvelle section dans `[projet].log.md`

## En résumé
Ajoute une entrée de session dans le journal de bord du projet. Structure : `## Jour N — [date] — [objectif]` / `### Session N — [résumé]`. Chaque session dans **sa propre section**, jamais dans celle d'une session précédente.
