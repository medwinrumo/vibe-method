## Rôle
**`/pdf`** — Génération de document PDF professionnel depuis un fichier markdown.

## Inputs
- Fichier `.md` source (proposition commerciale, CGV, devis, rapport)

## Output
Document PDF mis en forme professionnellement

## En résumé
Transforme un fichier markdown en PDF professionnel avec mise en page typographique correcte. Règles typographiques actées : `page-break-after: avoid` sur tous les titres. Vérification page par page avant livraison.
