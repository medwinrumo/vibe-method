## Rôle
**`/setup`** — Bootstrap technique : prérequis, dépendances, tooling, structure de dossiers, .env, premier lancement.

## Inputs
- `[projet].archi.md`
- `[projet].stack.md`

## Output
Repo initialisé et fonctionnel (pas de fichier wiki)

## En résumé
Configure l'environnement de développement : install des dépendances, structure de dossiers conforme à l'archi, fichiers .env (avec toutes les variables listées), configuration TypeScript, premier lancement validé. Tout est opérationnel avant le premier `/sessionCode`.
