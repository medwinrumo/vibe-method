## Rôle
**`/todo`** — Lecture de l'état du projet en début de session : sync GitHub Projects puis affichage de l'état courant.

## En résumé
Synchronise l'état local (`[projet].todo.md`) avec GitHub Projects (source de vérité). Affiche les tâches en cours, à faire, et bloquées. Point de départ obligatoire de toute session pour savoir où on en est.
