## Rôle
**`/zoom-out`** — Carte du module courant : responsabilité, callers, contrat public, termes du domaine. Pour se réorienter dans un fichier peu familier.

## Inputs
- Module ou fichier ciblé

## En résumé
Quand on est désorienté dans un module (nouveau dev sur le projet, module complexe, retour après longue absence), produit une carte rapide : ce que fait le module, qui l'appelle, ce qu'il expose, les termes métier qu'il utilise. Aide à comprendre le contexte avant de modifier quoi que ce soit.

**Transversal — invocable à tout moment**
